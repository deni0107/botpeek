# Changelog

## 0.1.0 (unreleased)

First public beta, tested with macOS 26 and Grok Bot 0.78.1.

- Shows a character when a Grok Bot bot asks a question, needs an approval or a form,
  and never for ordinary messages or unread counts
- Reads bot names and avatars from Grok Bot's local data, drawn with Grok Bot's own renderer
- Answers choice, multi-select and typed questions in the background, and confirms delivery
- Opt-in inline approvals with a second confirmation
- Queue for several bots with snooze, dismiss and a menu-bar list
- ⌃⌥B global shortcut and keyboard controls in the bubble
- Demo mode, settings, onboarding and a privacy-preserving diagnostics export
- Universal DMG and ZIP releases with SHA-256 checksums
